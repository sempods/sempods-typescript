# SDK 0.7.0 (in preparation)

These notes collect the changes for 0.7.0. The prerelease `0.7.0-dev.1`
carries all of them under the npm dist-tag `next`, for testing apps against
the new packages; `latest` stays 0.6.0 until 0.7.0 is released. Install it
with exact versions:

```sh
npm install --save-exact @sempods/client-sdk@0.7.0-dev.1 @sempods/app-sdk@0.7.0-dev.1 @sempods/app-ui@0.7.0-dev.1
```

For upgrade steps, see the
[migration guide](../migration.md#from-060-to-070).

## A UI kit for apps: `@sempods/app-ui`

A third package, released with the same version as `@sempods/client-sdk` and
`@sempods/app-sdk`. It is optional: apps that use their own components keep
working as before.

- **Components.** shadcn/ui components (style `aria-nova`) on React Aria
  Components: buttons, calendar, dialog, menu, popover, select, inputs and text
  areas, as built JavaScript with TypeScript declarations.
- **Adapters for SDK screens.** `ScreenDialog` (a routed screen, full screen on
  phones, compatible with SDK confirmations), `HeaderMenu` (submenus with
  checked choices), `DateChooser` (a calendar-date chooser for the SDK's `date`
  field), `ActionButton` and `ActionLink` (large actions in the theme's
  variants, the latter a real link), `ActionGroup` (a row of actions that
  fills a phone's width) and `ChipGroup` with `Chip` (filter chips); `Badge`
  for read-only tags.
- **A router over the app's address model.** `useNav(model)`: the app keeps
  its places and addresses (`parse` and `format`), the router gives the shown
  `place`, `go`, `close(fallback)` and `link`, and `replaceUrl` for the
  runtime's sign-in return. Every switch, Back and Forward runs through the
  SDK's `navigate`, also when the person moves through the history again
  while the SDK asks; `close` returns to the in-app opener or replaces with
  the fallback after a direct entry; only known addresses are replaced by
  their canonical form. It replaces the `routes.ts` copied into apps by the
  template, so corrections reach existing apps.
- **A theme contract.** One stylesheet, `@sempods/app-ui/styles.css`, for
  Tailwind CSS 4: palette roles in `light-dark()`, the action variants
  `data-actions` and `data-secondary`, the bridge to the SDK's `--sempods-*`
  tokens and a solid focus outline. The variants reach the SDK's actions too:
  Save, Cancel and confirmations look like the app's buttons of the same role.
  The app keeps its own `theme.css`. `@sempods/app-ui/theme-check` checks an
  app's palette for every action variant in light and dark and names the
  roles to adjust.
- **Updates reach apps.** Fixes arrive through a dependency update instead of
  edits in copied component source.

Install it next to app-sdk of the same minor version, with React 19 and
Tailwind CSS 4.1 or newer; the
[package README](../../packages/app-ui/README.md) describes the setup.

Its browser gate runs with the installed packages in Chromium and WebKit, and
in Firefox on Linux, against a loopback fixture Pod, including the routing
matrix of the template's routing spike. It does not establish
behaviour on iOS, in an installed PWA or with real people.

## App SDK

- **Action tokens with three parts.** The main action and the other actions
  of SDK surfaces each take a surface, text and border token
  (`--sempods-primary-border`, `--sempods-secondary-bg` and
  `--sempods-secondary-border` are new); the defaults keep the previous look.
  A hovered main action now mixes its text into its surface. The
  [token table](../react-authoring.md#shared-sdk-appearance) lists them.
- **Styles in a cascade layer.** The SDK's sheets sit in `@layer sempods` with
  tokens for field borders and the focus ring, so a host's UI kit can order
  and theme them. Unlayered global app CSS now wins over SDK rules: see the
  [migration guide](../migration.md#sdk-styles-in-a-cascade-layer).
- **Leave prompt.** While a draft or a write is unsaved or unconfirmed,
  reloading or closing the tab asks first (`unloadPrompt={false}` turns it
  off).
- **One chooser across Pods.** `useApp().selectTarget` switches Pod and
  Context in one guarded step; `usePodContexts` lists the Contexts of every
  connected Pod for one chooser.
- **`ResourceEditor`.** `presentation` (`'card'` or `'plain'`) sets only the
  frame. With `onClose`, Escape anywhere in the editor asks before
  discarding changes and does not close an enclosing app dialog.
- **Skipped records.** `useList` and `usePodList` pass on `skippedRecords`:
  which entries a mapping skipped and why, without repairing them.
- **Phones.** `AppAccess`'s Pods & sharing dialog is a bottom sheet up to
  30rem wide.

## Client SDK

- **Calendar dates.** `date(predicate)` owns one `xsd:date` as a day, never a
  midnight instant; with `orDateTime` it also keeps a zoned `xsd:dateTime`.
- **Text language variants.** `selectTextVariant`, `editTextVariant` and
  `patchTextVariant` select and edit one preferred language variant without
  touching the others.
