These notes collect changes for the next release while it is prepared; the
release preparation completes them. For upgrade steps so far, see the

## A UI kit for apps: `@sempods/app-ui`

A third package, released with the same version as `@sempods/client-sdk` and
`@sempods/app-sdk`. It is optional: apps that use their own components keep
working as before.

- **Components.** shadcn/ui components (style `aria-nova`) on React Aria
  Components: buttons, calendar, dialog, menu, popover, select, inputs and text
  areas, as built JavaScript with TypeScript declarations.
- **Adapters for SDK screens.** `ScreenDialog` (a routed screen, full screen on
  phones, compatible with SDK confirmations), `HeaderMenu` (submenus with
  checked choices), `DateChooser` (a calendar-date chooser for the SDK's `date`
  field) and `ActionButton` (large actions in the theme's variants).
- **A router over the app's address model.** `useNav(model)`: the app keeps
  its places and addresses (`parse` and `format`), the router gives the shown
  `place`, `go`, `close(fallback)` and `link`, and `replaceUrl` for the
  runtime's sign-in return. Every switch, Back and Forward runs through the
  SDK's `navigate`, also when the person moves through the history again
  while the SDK asks; `close` returns to the in-app opener or replaces with
  the fallback after a direct entry; only known addresses are replaced by
  their canonical form. It replaces the `routes.ts` copied into apps by the
  template, so corrections reach existing apps.
- **A theme contract.** One stylesheet, `@sempods/app-ui/styles.css`, for
  Tailwind CSS 4: palette roles in `light-dark()`, the action variants
  `data-actions` and `data-secondary`, the bridge to the SDK's `--sempods-*`
  tokens and a solid focus outline. The app keeps its own `theme.css`.
- **Updates reach apps.** Fixes arrive through a dependency update instead of
  edits in copied component source.

Install it next to app-sdk of the same minor version, with React 19 and
Tailwind CSS 4.1 or newer; the
[package README](../../packages/app-ui/README.md) describes the setup.

Its browser gate runs with the installed packages in Chromium and WebKit, and
in Firefox on Linux, against a loopback fixture Pod, including the routing
matrix of the template's routing spike. It does not establish
behaviour on iOS, in an installed PWA or with real people.
